Install and setup

Requires an Atlassian Cloud site with Rovo enabled. Shortfall's drafting features run through the Rovo agent. Jira and Confluence must both be present on the site.

1. Install the app

Open the installation link, pick your site and confirm the requested scopes.

  • Jira scopes let Shortfall read open work and create response items — writes happen only when your admin enables them or a person confirms.
  • Confluence scopes let it search your pages and show shortage notices.
  • Outbound network access is limited to api.fda.gov and rxnav.nlm.nih.gov (public drug data). Nothing about your site leaves it.

2. Grant Teamwork Graph scopes (organization admin)

Owner and team lookups run through the Teamwork Graph API. An organization admin grants the granular scopes in Atlassian Administration:

  1. Go to Atlassian Administration → Apps → your site → Connected apps.
  2. Select Shortfall, open Permissions.
  3. Enable the Teamwork Graph scopes: users, teams, Confluence pages, Jira work items.
Scope changes take about a minute to apply. If a scope is left off, the app keeps working in reduced mode and lists what it could not read on the dashboard — nothing fails silently.

3. First-run setup

  1. Open Apps → Shortfall in Jira. The setup screen appears.
  2. Choose clinical spaces — pick the Confluence spaces that hold protocols, order sets and guidelines. Only these count in the impact map.
  3. Add the drug list — paste rows, upload a CSV (name, ndc, form), or load the sample hospital for a realistic demo.
  4. Pick a response mode — automatic (a Jira work item opens per new matched shortage) or manual (review first, create on demand).
  5. Choose the response project — the Jira project response items live in.
  6. Run the first sync — the FDA list is fetched, matched, and the impact map is built. Progress is shown live.

4. Daily operation

A scheduled trigger syncs once a day. From the dashboard you can run Sync now, see the last run's result, exposure by space, overdue tasks and time from FDA posting to response.

5. The agent

Find Shortfall in Rovo Chat. Ask things like "What does the cefazolin shortage affect and what did we do last time?" The agent answers with linked sources, and drafts conservation plans for approval — it never recommends a substitute drug on its own.

6. Removing the sample hospital

If you loaded the sample hospital, the setup screen's remove button deletes exactly the space, pages, drug list and Jira project it created — nothing else.
