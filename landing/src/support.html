Report a problem

Open an issue on the issue tracker with:

  • What you expected and what happened instead
  • The sync run result from the dashboard, if relevant
  • Whether the app is in reduced mode (the dashboard lists unreadable scopes)
Never include patient information in a report — Shortfall does not handle it and neither should a bug report.

Reduced mode checklist

If owners or page data look incomplete:

  1. Open the dashboard — it lists exactly which scopes or products are unreadable.
  2. Ask your organization admin to check the Teamwork Graph permissions under Connected apps → Shortfall → Permissions.
  3. Wait about a minute after scope changes, then run Sync now.
